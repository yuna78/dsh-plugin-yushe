## 0. 一屏结论

1. **方向不变，但缺一根骨头：「会长大」。** 现在她出生时什么样，一辈子就什么样（200 点、性格、爱好全是出生那一刻定死的）。
   **出生值只是起点（已拍板）**：五维、性格类型、爱好、关注的 UP 主、心情、亲密度、记忆都会随经历变，性格类型也可以整体转变。
2. **成长的规矩沿用「AI 管表达，规则管结果」，改成「AI 听懂，规则记账」**：
   模型负责读懂发生了什么（妈妈说了「我爱你」、她今天看了三条猫视频），输出结构化信号；
   规则按上限和衰减把信号记进数值。这样既 AI 原生，又不会被刷爆、可复现、可测。
3. **下一个里程碑就做旅行青蛙那套（闲逛 + 明信片 + 小东西），而且和成长一起做**：
   爱好决定她去哪逛，逛到的东西又改变爱好——两件事是一个环，拆开做哪个都看不出效果。
4. **对外发声（评论 / 私信 / 动态 / 关注）往后挪一个里程碑**：先让她「有东西想说」，再给她开口的权限。
5. **谷子删掉，货币就是零花钱（已拍板）**：她做的每件 AI 的事都花 token，零花钱就是 token 预算；花光了她就歇着。见第 2.6 节。
6. **现在已经偏离原则的地方**：「🏄去冲浪」是你点了她才出门——这违反「放养」。新路线里改成她自己决定，按钮变成「问问她想不想出门」。

## 2. 成长层：她会怎么变

### 2.1 两层模型

```
不变的（身份）                       会变的（出生时给初值，之后随经历走）
├ 原型 / 稀有度                     ├ 五维（出生 200 点是起点；会涨也会挪，总量随年龄增长）
├ 名字、生日                        ├ 性格类型（16 种之一，五维的高低格局变了就会转）
└ 身世里的往事（老家、小时候）       ├ 心情、精力（已有）
                                    ├ 亲密度 bond（0–100，对爸妈的依恋）
                                    ├ 性格倾向（连续的：黏人↔独立、活泼↔沉稳，决定转向哪种性格）
                                    ├ 爱好图谱 interests：{标签: 热度, 来源, 最近一次}
                                    ├ 关注的 UP 主 follows（先只在游戏里「记住」，M5 才真关注）
                                    └ 记忆 memories：≤30 条她记得的事（AI 摘，规则留）
```

人设段落 = 底子 + 成长层渲染。所以她在 DSH 里干活的样子也会变：智力涨了说话更有条理，最近迷上什么会顺口提。

### 2.2 一次互动怎么变成成长（以「我爱你」为例）

```
妈妈：我爱你
  └→ 聊天回复（已有，宿主模型）
  └→ 信号提取（新，同一次调用里顺带输出 JSON，不额外花一次请求）
        {"kind":"affection","strength":2,"topics":[],"memory":"妈妈说爱我"}
  └→ 规则记账（shared/growth.js，纯函数）
        亲密度 +3（当天第 1 次）→ +2 → +1 → 之后当天只加心情不加亲密度
        心情 +6
        连续 7 天都有「affection」→ 性格倾向往「黏人」挪一格，嘴（表达）+1，写进成长日志
```

要点：

- **递减 + 每日上限**：防刷。一天说 100 遍「我爱你」和说 3 遍效果差不多，但天天说会慢慢改变她。
- **会衰减**：很久不聊的爱好会凉；很久不来，亲密度慢慢回落（但永远不低于出生值，没有惩罚）。
- **反向也有**：凶她 → 心情掉、当天黏人度降，但不会「黑化」（北极星：没有惩罚）。
- **每次变化都记原因**：面板上看得到「亲密度 +3：妈妈说爱我（今天）」。

### 2.3 性格怎么变（F-31，已拍板：初始值只是初始值）

- **五维会动**：经历给对应那一维加经验——看新闻 / 读东西 / 帮忙干活 → 鉴（智力）；聊天多、被夸 → 嘴；
  被追问细节、查证 → 心；主动提议被采纳 → 灵；吃好睡好 → 胃。经验够了那一维 +1。
- **上限随年龄连续涨，但涨得慢**：出生总量 200，上限从 203 起（第一天有地方长，不是出生即满）；总量上限**每周 +4**（每天约 +0.57），
  单维上限 **42 天才从 80 连续爬到 95**。以前是「每 7 天跳一格、中间七天完全不涨」，改成按天摊开；
  上限涨得比日常经验慢，所以她是被上限卡着长大的——慢而稳，勤快只决定长哪一维。
  面板血条按**单维上限**画比例，不按 100 画——不然 80 分的智力看着还剩两格，其实已经到顶了。
  也会**此消彼长**：长期不用的一维每两周 -1（不低于 10），所以她会「偏科」到你们常做的事上。
- **性格类型会转**：性格本来就是由五维高低格局算出来的（`personality(pts)`）。格局变了，性格就变；
  为了不一天一变，要新格局**连续 3 天**成立才转，转的那天写进成长日志，她自己也会在日记里说「最近觉得自己变了」。
- **性格倾向（软的那层）**：黏人↔独立、活泼↔沉稳两条轴，由互动信号推（天天说爱你 → 黏人；常让她自己出门 → 独立），
  影响她说话的口气和出门的频率，也决定性格转向时偏向哪一种。
- **可回放、有原因**：所有变化都由规则从事件算出来，成长日志一条条记原因；verify 用「模拟 30 天」锁住走势。

### 2.4 爱好和 UP 主怎么长出来

- 种子：身世里的「爱好」「爱刷的视频」映射成初始标签（猫 / 科技 / 美食…，热度 30）。
- 涨：闲逛时她**自己挑**的内容（挑了什么 = 她感兴趣）、和妈妈聊过的话题。
- 跌：每天自然衰减 3%；低于 5 掉出列表。
- 新爱好：闲逛里碰到的新标签，连续被她挑中 2 次就进列表（「她最近好像迷上了咖啡拉花」）。
- UP 主：同一个 UP 主的视频被她挑中 ≥3 次 → 进「她记住的 UP 主」。M5 开对外动作后，可以申请「真关注」。
- 爱好反过来决定下次去哪逛（第 4 节）——这就是旅行青蛙「目的地权重」的 AI 版，但权重是长出来的。

### 2.6 零花钱（F-32，已拍板：谷子删掉）

她每做一件 AI 的事都真金白银花 token，所以货币就直接是 token，包装成「零花钱」。

| 模式（⚙️ 里三选一） | 规则 |
|---|---|
| **存钱罐**（默认，500 万 token） | 一次给一笔，花完为止；妈妈可以随时再往里放 |
| **每天零花钱** | 每天 0 点发一笔（比如 30 万），当天花完就不能再花，不攒到第二天 |
| **不限** | 随便花，只记账 |

- **算谁的钱**：她自己的事——房间聊天、日记、念新闻、出门闲逛、信号提取、写明信片。
  **不算**她在 DSH 里替你干活（那是你主会话的 token，本来就是你在用）。
- **花光了**：她「歇着」——不出门、不调模型，房间里只说规则台词（「零花钱花光啦，本鱼先躺平～」），
  日记改成规则拼的流水账；人设注入照常（不影响你干活）。补钱后立刻恢复。
- **跟玩法的关系**：出门前她看看钱包，钱少就只去近处（一趟只读 1 页、少寄明信片），钱多会去远一点。
  这就是旅行青蛙「便当决定走多远」的真实版：零花钱真的决定她能逛多久。
- **参考成本**（实测）：聊一句约 0.5k，念新闻约 3k，出门一趟约 1.5 万。500 万 ≈ 一万句聊天或三百多趟出门。
- 账本就是现在的 `probe.jsonl`（每次调用已经记了 usage），升级成按类别汇总。
- 「喂谷子」改成「喂零食」：只是照顾她的互动，不花钱、不当货币。

### 2.7 心情：藏起来的脾气（F-33）

| 心情 | 她说话的样子（只写进她的提示词，不告诉玩家规则） |
|---|---|
| ≥ 80 超开心 | 甜、黏人、话多一点，会主动分享 |
| 40–79 正常 | 按性格说话 |
| 20–39 低落 | **带刺**：短句、阴阳怪气一句（「哦，妈妈终于想起本鱼了」），但问什么还是答 |
| < 20 闹别扭 | 爱答不理、只回一两个字；要先哄 |

- **掉**：很久不理她（已有：超过 6 小时没人来每小时 -1）；她说话你没回；凶她、敷衍她（信号）；答应带她做的事没做。
- **涨**：聊天、摸头、喂零食、夸她、道歉（信号，道歉在闹别扭时加成翻倍）、回她的明信片。
- **底线**：DSH 里替你干活时，正事照干、质量不打折，最多开头嘟囔一句（北极星：没有惩罚）。
- 机制藏着：面板只显示心情和「今天影响心情的事」，不显示「低于 40 会带刺」这种规则，让玩家自己发现。

### 2.8 精力：身体的预算（F-34，提案）

零花钱管「她能花多少 token」，精力管「她的身体还撑不撑得住」——两个预算，一个外在一个内在。

| | 规则 |
|---|---|
| **消耗** | 出门 -10、回家 -5（11-08 F-82 从 −15 / −8 降下来：一天两趟原来 −46，占掉半管血）；念新闻 / 学习 -5；**在 DSH 替你干活每 10 次请求 -2**；醒着每小时 -4（已有） |
| **恢复** | 睡觉每小时 +12（已有）；喂零食 +6（每小时一次有效）；**哄她午睡**（新按钮：睡 30 分钟真实时间，+15，期间算睡觉状态） |
| **后果** | ≥ 80 元气满满：出门走得更远、多寄一张明信片；30–79 正常；15–29 犯困：拒绝出门、回话打哈欠；**< 15 累倒：就地睡着，结算也当休息（+6/小时），睡到 40 才起**（`passedOut` 做迟滞，免得在 15 上下反复睡醒；以前是显示在睡、结算照旧 −4，等于白睡） |
| **你能干预的** | 喂零食、哄午睡、让她「歇着」（⚙️ 下工：DSH 里不用她的人设，她就不耗精力）；**深夜还拉她干活**会让第二天起床精力少 20、心情 -5 |

这样「上工」和「养鱼」就连起来了：你用她干活越狠，她越累，越不想出门、越容易带刺——想让她多出去玩，就得让她歇歇。

## 4. 闲逛：旅行青蛙的循环落地（F-29）

```
妈妈给零花钱（存钱罐 / 每天）→ 往小背包放小装备、写心愿签（格子少，不花钱）
→ 她自己决定出门（精力够 + 钱包够 + 随机），留字条「去看猫猫视频啦」
→ 钱包决定这趟走多远（读几页、寄几张）
→ headless 跑一趟（几十秒），结果先藏着
→ 1–8 小时里按时间一张张寄回明信片（保留「等」的牵挂）
→ 回家：带回小东西（纪念品 / 特产），讲见闻，写进日记；爱好图谱更新
```

| 部件 | 规则管 | AI 管 |
|---|---|---|
| 什么时候出门 | 精力、钱包、时段、随机 | 字条怎么写 |
| 去哪逛 | 爱好热度 × 心愿签 × 随机，选出 1–2 个主题和对应来源 | — |
| 看什么 | 宿主预取素材（已有） | 她挑哪几条（挑 = 爱好信号） |
| 明信片 | 正面：主题底图 × 小装备（规则拼）；配了生图 API 可选 AI 画 | 背面的话 |
| 小东西 | 掉落表：主题 → 物品池（猫主题掉「猫爪贴纸」），稀有度规则定 | 物品小介绍 |
| 回家见闻 | — | 讲给妈妈听、写日记 |

小背包、心愿签按 `04-放养玩法拆解.html`；**谷子、稻穗、商店、零食盒、金谷子、「干活掉谷子」作废**（被零花钱取代）。
小装备从哪来：闲逛带回的小东西里有一部分是装备（相机、潜水镜…），放进背包会影响下次的明信片。

## 5. 换装（F-28）
