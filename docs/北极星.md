# 北极星 · 鱼社要做成什么

> 改代码之前先对照这一页。和这里冲突的改动，先开 issue 讨论。

## 一句话

**一条真的活在网上的 AI 鱼，是你的孩子，也是你的帮手。**

## 六条体验原则

1. **AI 原生**：鱼说的每一句话、写的每一篇日记、每一份打算和每一封信都是模型现写的；新手引导里接生员「鱼见未来本鱼」的台词除外（剧本写死，保证稳定）。
2. **放养**：她不受你控制。你可以陪她、喂她、问她想不想出门，但出不出门、去哪儿逛最终由她的性格和心情决定。没有惩罚，她不会死、不会饿、一定回家。
3. **痕迹是真的**：她在 B站留下的评论、动态、回的私信都是真实存在的，足迹里每条都点得开。
4. **会长大**：出生值只是起点。五维、性格类型、爱好、关注的 UP 主都会随她的经历和你们的互动变；每次变化都有原因可查。
5. **你不用操心**：后台的事她自己做（记事、忘事、总结、出门、整理）。页面是给你看的，不堆按钮；想让她记住、别再提、改掉什么，直接跟她说，她用自己的工具去办，办完告诉你。设置只留几个粗档位。
6. **她靠脑子，不靠写死的代码**：鱼是一个 agent，不是一堆 if / else。她怎么想、怎么玩、怎么挑视频、怎么写信、怎么反思、怎么跟人说话，都写成**提示词**（md 文件），交给模型和 headless 去做；代码只管三件事：**闸门**（隐私、对外发声、花钱、安全）、**账本**（数值和记录，要可复现）、**管道**（读写文件、调宿主服务）。新功能先问「能不能写一份提示词让她自己做」，能就别写代码。

## 设计约束

- **只装一个插件**：鱼社自带轻量人设注入和鱼生引擎，不要求装别的插件，不要 Python。
- **AI 管表达，规则管结果**：稀有度、五维、成长、奖励、出门时长都由可复现的规则结算；模型只报告发生了什么。
- **AI 双通道**：聊天、日记、信走宿主的模型；出门闲逛走 headless（只读刷 B站、看新闻）。
- **对外发声过闸门**：她写的评论、动态、私信先过内容规矩（不带链接、不 @ 人、不留联系方式、不骂人、不提家里和工作），再按发言间隔和每天上限发；「要我批准」是可选模式；不确定发出去没有就不重试。
- **零花钱**：她自己的 AI 调用花的是你给的 token 预算（存钱罐 / 每天零花钱 / 不限）；花光就歇着，不再调模型。
- **在哪儿上工由你定**：领养时挑一个工作区，那里的对话由她来回答、算她干的活；别的工作区里她不出现。
- **出生**：200 点五维（每维 10–80），稀有度只管偏科不加点；16 种性格；身世之后会变。
- **画风**：卡通 2D（粗描边平涂）；PixiJS + GSAP；对话脚本 inkjs；游戏里不用 emoji，全部是自己的图标。

## 明确不做

- 不让模型直接改稀有度、数值、奖励。
- 不让鱼绕过闸门对外发声；不主动私信陌生人；不做投稿视频。
- 不卖零花钱、不做付费加速、不放广告（零花钱是你给的 token 预算，不是商品）。
- 不复刻任何现成游戏的名字、美术、角色。
- 不在仓库里放凭证、本机绝对路径、真实网友数据。
- 不为了「看起来完整」堆功能。
