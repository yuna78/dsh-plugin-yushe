# 美术来源

鱼社里的立绘、姿势、房间背景、图标都是**本项目原创生成**的（用 OpenAI 兼容的图像生成服务，文生图 + 以本角色站姿为参考的图生图），统一画风：卡通 2D、粗描边平涂、Q 版 3.5 头身。

- 不包含任何动漫 / 游戏 IP 角色，不描图、不参考具体作品；
- 不使用真人肖像，不做擦边内容；
- 背景统一用纯品红生成后抠图（`assets/` 里是抠好的 webp）；
- 游戏里不用 emoji，图标是自己画的一套。

| 内容 | 路径 |
|---|---|
| 15 位角色的站姿 / 头像 / 睡觉 | `assets/girl-<鱼种>.webp`、`assets/head-<鱼种>.webp`、`assets/sleep-<鱼种>.webp` |
| 每位角色 14 个姿势 | `assets/pose/<鱼种>/<姿势>.webp` |
| 接生员「鱼见未来本鱼」 | `assets/benyu/<姿势>.webp` |
| 她的家（10 间房）+ 鱼塘 | `assets/bg/` |
| 图标 | `assets/icons/` |
